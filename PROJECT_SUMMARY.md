# 📝 NoteBoard - Project Summary

> A comprehensive, production-ready Web3 social platform built on Base blockchain

## 🎯 Project Overview

NoteBoard is a fully-featured decentralized social media platform that rivals traditional Web2 platforms while maintaining true ownership, transparency, and user rewards through blockchain technology.

## 🔗 Smart Contract Features

### User Management
- User profiles with bio, avatar, username
- Follow/unfollow system
- Block & mute functionality
- User verification & badges
- Premium memberships
- NFT profile pictures

### Content Creation
- Post notes (280 chars max)
- Edit & delete notes
- Add tags (up to 5)
- Attach media (IPFS)
- Create polls (2-10 options)
- Post replies
- Mention users
- Thread conversations

### Social Interactions
- Like/unlike notes
- 6 emoji reactions
- Repost notes
- Bookmark notes
- Pin notes (max 3)
- Tip creators with ETH

### Monetization
- Reward points system (10/note, 5/like, 3/reply)
- Convert points → ETH
- Creator subscriptions
- Premium accounts (0.01 ETH)
- Community fees
- Platform fees (1%)

### Communities
- Create public/private communities
- Set subscription fees
- Member management
- Community-specific content

### Moderation
- Content reporting
- Auto-delete at 10 reports
- Moderator roles
- User verification
- Admin dashboard

### Discovery
- Search functionality
- Trending algorithm
- Tag-based filtering
- Personalized feed
- Leaderboards

## 🛠️ Tech Stack

### Frontend
- **Framework:** Next.js 14 (App Router)
- **UI Library:** React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Web3:** Wagmi v2, Viem v2
- **Wallet:** Reown AppKit

### Blockchain
- **Network:** Base (Ethereum L2)
- **Contract Language:** Solidity 0.8.28
- **Development:** Hardhat
- **Storage:** IPFS (decentralized)

### Development Tools
- **Version Control:** Git
- **Package Manager:** npm
- **Linting:** ESLint
- **Formatting:** Prettier
